# LD360 display preview

`ld360-display-blank.png` is a transparent product cutout prepared from the user's supplied LD360 photograph using the built-in image generation tool. The source background and fixed screen text were removed; the app draws live seven-segment fields over the blank glass in `CoolerDisplayPreview.cs`.

The PNG is embedded as a WPF resource, so no external image service or file is needed at runtime. `CoolerRgbStrip` separates its RGB emission into a mask at runtime and keeps a neutral product layer beneath it. The strip follows **ARGB header 2**, controller **zone 6** on the qualified Z890 board, using Sora's saved color, brightness and effect. It never uses zone 2 (the SSD heatsink).

For Sora-driven animated sync, the preview consumes the exact last color successfully sent to the motherboard, without opening hardware or scaling brightness twice. Native controller effects use the selected parameters and controller timing tables; their animation phase is an approximation because the controller does not expose a live phase readback. An individual Rainbow/Wave zone follows the same Color cycle fallback used by the hardware path; only a complete board-wide Rainbow look produces a spatial rainbow.

No saved header-2 look shows an unlit strip. Animation runs only while the preview is visible and stops for reduced motion or unloading. The preview writes neither lighting preferences nor hardware. Only telemetry and existing display preferences use the cooler's display protocol; physical RGB continues through the motherboard lighting service.
