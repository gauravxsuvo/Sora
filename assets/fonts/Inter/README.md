# Inter 4.1

Official source: https://github.com/rsms/inter/releases/tag/v4.1

Unmodified static TrueType faces: Light, Regular, Medium, SemiBold and Bold.
Sora embeds these files as WPF resources through the shared UIFont token. No system font installation or runtime download is required.
