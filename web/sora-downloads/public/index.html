A FEW THINGS BEFORE YOU START
Need a hand?

      
How do I install or update Sora?
Install the .NET 8 Windows Desktop Runtime (x64) if needed. Exit an existing Sora from its tray menu, then run the installer. Normal upgrades keep your saved settings. Setup may ask for administrator permission because Sora talks to hardware.

      
Chrome blocked the download or Windows shows a warning. Why?
This installer does not have a Windows Authenticode publisher signature. A new or uncommon executable can also receive a browser warning. Sora's own update signatures verify release files, but they do not give a file Chrome or Windows reputation.
If Chrome says the file is suspicious or dangerous, check the exact warning, scan the downloaded file with Windows Security where available, and report it using Sora's issue tracker. Do not turn off Safe Browsing or antivirus protection to install Sora. Google explains download warnings here.

      
Why is an old Sora icon still in my Start menu?
Windows can keep an older shortcut icon cached after an upgrade. New setup versions use a dedicated icon file and refresh Sora shortcuts. If an old pinned or Recent entry remains, unpin it and pin Sora again from the installed shortcut. You do not need to reinstall repeatedly.

      
What happens when I uninstall?
Exit Sora from its tray menu first. You can remove saved profiles, preferences, logs, recovery backups and update cache, or keep your data for a later reinstall. Complete removal covers Sora data in registered Windows user profiles. Removing recovery backups is permanent. Shared .NET and PawnIO dependencies, hardware firmware and files you exported elsewhere are kept.

      
Which hardware is this built for?
Sora is a personal project focused on the Gigabyte Z890 GAMING X WIFI7 PC and peripherals listed above. Check the exact device coverage before downloading. Another motherboard, laptop, cooler or mouse may use a different interface and have no controls in Sora.
