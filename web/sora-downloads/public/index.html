Before you install
Do I need the .NET runtime?
Yes. Install the .NET 8 Windows Desktop Runtime (x64) if it is not already installed. Sora’s installer checks this prerequisite.
Why might Windows say “unknown publisher”?
Sora uses a free release-signing key to authenticate in-app updates. Its Windows executable has no paid Authenticode publisher certificate, so Windows may show an unknown-publisher or SmartScreen warning. Download only from the official Sora site or repository.
Will an update change my profiles or startup settings?
Application upgrades retain the saved profiles and startup preference. Installation waits for Sora to close safely. BIOS and device-driver installations remain separate, manual actions.
