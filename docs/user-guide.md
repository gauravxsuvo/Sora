# Using Sora

Sora detects connected hardware and displays applicable device pages. Settings and Updates remain available on every computer. A missing or unsupported device does not enable its hardware controls.

## Device controls

Open a device page to read its current state. Edit settings, then choose Apply. Applying a profile is separate from editing or saving it. Close other applications controlling the same device before applying.

Sora saves original settings before taking control where restoration is supported. Use the page's restore or stop action to release control. Exit Sora through its tray menu before installing an upgrade or uninstalling.

## Cooler display

The DeepCool LD360 page displays CPU temperature, utilization, and package power. Valid readings and an available USB connection are required before display output starts. Configure automatic display output on that page. Computers without the cooler do not show these settings.

## Connection changes

New devices are detected automatically. Saved data remains local when a device is unplugged. Never apply another model's settings to a newly connected device. Unsupported features remain unavailable even if a device uses the same brand or protocol family.

## Updates and saved data

Application updates require an explicit install-and-restart action. Hardware downloads are separate and are not installed by Sora. Data is stored under the Windows user's local application-data folder. Uninstall can retain or remove that data.

For setup and permissions, see [installation](program-files-installation.md).
## Lenovo Legion preview

Detected Legion laptops have a **Lenovo Legion** page for experimental power, charging, graphics-mode and keyboard controls. Features depend on the available firmware/driver/controller interfaces. See [Legion coverage and limitations](Lenovo-Legion.md).
