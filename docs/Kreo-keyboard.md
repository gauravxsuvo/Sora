# Kreo keyboards

Supported wired keyboards expose model-specific key mapping and lighting. Select the connected model, read its current state, edit settings, and Apply. Key positions and effect availability come from the supported model definition.

Receiver capabilities differ from wired capabilities. An attached receiver alone does not establish that every keyboard setting is available. Wake a wireless keyboard before reading it. Refresh after changing connections.

Close competing keyboard controllers before Apply. Original configuration is saved before changes; interrupted or failed writes use the supported restoration workflow. Import only profiles matching the connected model.

See the [user guide](user-guide.md).
