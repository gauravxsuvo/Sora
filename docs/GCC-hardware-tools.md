# Hardware maintenance

Application updates, drivers, BIOS, and peripheral firmware are separate maintenance routes. Sora's automatic motherboard catalog covers matched Gigabyte BIOS and driver entries. Catalog versions can lag manufacturer support pages.

Sora does not automatically establish firmware availability for every GPU, SSD, mouse, keyboard, receiver, or cooler. A support link does not establish that an update exists or is needed.

Confirm the exact hardware model and revision before downloading a package. Follow official prerequisites, backup and recovery instructions. Sora does not install downloaded drivers, flash firmware, or update the BIOS.

Storage health and displayed firmware versions are useful inventory, not proof that a device is current. See the [user guide](user-guide.md).
