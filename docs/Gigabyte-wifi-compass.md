# Wi-Fi measurements

Sora reads Windows WLAN connection information and cached network results. Refresh does not force a wireless scan. Stale results remain distinct from fresh measurements.

Choose an adapter and access point, then use the history or manual antenna-position comparison. Antenna direction is supplied by the user; Sora does not sense physical orientation.

A disabled or failed adapter may be unavailable to Windows WLAN. Use Windows network settings and the adapter manufacturer's recovery guidance. Network names and access-point identifiers can be personal information; review exports before sharing.
