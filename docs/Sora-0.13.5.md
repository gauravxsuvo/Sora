# Sora 0.13.5

Clearer fan editing and a cooler preview that follows your lighting.

- Fixed double focus outlines and inconsistent thin borders on fan header selections. Rows now use one consistent border while retaining a visible keyboard focus state.
- Kept chart and table point selections together. Remove a selected curve point with the button beside the chart, its right-click menu, or Delete while the chart has focus. The final 100% point and the two-point minimum remain protected.
- Replaced the generic cooler preview with a smooth LD360 display image, transparent background, no hose connectors, and live seven-segment temperature, package power and usage readings. Temperature units and leading-zero preferences update the preview; stale or missing readings show dashes.
- Connected the preview's RGB strips to ARGB header 2's color, brightness and effect in Sora. Sora-driven animations share the color frames sent to the motherboard; native controller effects match the selected look with an approximate animation phase. Preview animation stops when hidden or reduced motion is enabled.
- Improved the website logo's small-size rendering with inline vector artwork and a pixel-aligned download-card size.

Exit Sora through its tray menu before installing. Normal upgrades preserve existing profiles and preferences.
