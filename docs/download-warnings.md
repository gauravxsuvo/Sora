# Download warnings

Sora installers currently have no Windows Authenticode publisher signature. Sora's release signatures and SHA-256 checks protect its own update channel; they do not establish browser or Windows download reputation.

Do not disable browser protection or antivirus software to install Sora. Check the exact warning, verify the source and version, and report problems through the issue tracker. Follow your browser's built-in review guidance where available.

See [Google's download guidance](https://support.google.com/chrome/answer/6261569).
